# Harsha Vardhan A S — Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript. No installation, subscriptions, API keys, or build tools are required.

## View
Extract the ZIP, then double-click `index.html`. Keep the files together. JavaScript must be enabled.

## Edit
- `content.js`: profile information, academic details, skills, projects, internship, achievements, activities, and goals.
- `index.html`: hero name, main navigation, contact buttons, email links, footer name, page title, and description. When changing name, college, year, or email, update these repeated display values here as well as in `content.js`.
- `styles.css`: colours (variables at the top), fonts, spacing, layout, and mobile styling.
- `app.js`: rendering and print behaviour. Usually no changes are needed.
- `assets/harsha.jpg`: your photo. Replace with another JPEG using the same filename. The portrait is framed with CSS; the original image is not edited.

Save your changes and refresh the browser. Arrays in `content.js` accept additional entries matching the existing format. Keep quotes and commas valid. This website has no login-based editing dashboard: edit the source files directly.

## Publishing
Upload `index.html`, `styles.css`, `content.js`, `app.js` and `assets/` to any static website host. No backend is needed. Updates to the downloaded files do not automatically change the hosted Sites version; ask to republish the updated source.

## Print
Use “Print / save PDF” in the footer. Project details expand automatically. Choose Save as PDF in your browser’s print dialog.
